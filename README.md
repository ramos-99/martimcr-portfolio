# martimcr.com

Personal portfolio of Martim C. Ramos: systems programming, Linux, Rust and eBPF.

## Stack

- Next.js (App Router), Tailwind CSS, Framer Motion
- Cloudflare Pages (static export)

## Run locally

```bash
git clone https://github.com/ramos-99/martimcr-portfolio.git
cd martimcr-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
